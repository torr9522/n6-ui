# N6 v0.1.0 Stable Milestone

## Baseline

N6 began from a validated N5 plus SS2022 development branch and was imported into an independent N6 Git history. The product was rebranded for N6 while retaining explicitly documented internal compatibility identifiers where migration risk made renaming inappropriate.

- Repository: `torr9522/n6-ui`
- Stable version: `v0.1.0`
- Release commit: `0b4f648511ca13054cef298223a80bd39e7980b1`
- Release tag: annotated `v0.1.0`
- Application asset SHA256: `cec81fea7a8e280f95a3d7ce7702c231e69dd9fb30196b8a4c40b51d6c55b6a3`
- Runtime release: `n6-runtime-26.5.3-amd64`
- Xray: Custom Xray 26.5.3 amd64
- Xray binary SHA256: `128f9c34811ee74b3770eef7010d011e3946e85dfab28f2ed1804e380461b05e`

## Repository and Runtime Independence

The installer, application release, update, raw-script, and runtime chain were moved to N6-owned sources. Executable provenance audits confirmed:

- N6 application and runtime fetches used `torr9522/n6-ui`.

N5 remains historical provenance and is not an N6 runtime dependency.

## Protocol Acceptance

SS2022 v0.1.0 supports single-user operation for three methods. Each method passed Browser creation, generated configuration validation, real external TCP requests, and real external UDP DNS queries:

- `2022-blake3-aes-128-gcm`
- `2022-blake3-aes-256-gcm`
- `2022-blake3-chacha20-poly1305`

Legacy protocol regression results:

- Legacy Shadowsocks: PASS
- VMess: PASS
- VLESS: PASS

SS2022 multi-user and EIH remain unsupported. Mihomo is the supported Clash-family subscription target for SS2022; Classic Clash does not emit SS2022 nodes.

## Independent-Egress Routing Acceptance

An independent no-auth SOCKS5 egress was validated without recording its address in repository history. Its real observed exit differed from the N6 host, excluding a self-loop.

- AI real routing: PASS
- Advanced exact-domain real routing: PASS
- Pool-member real routing: PASS
- Pool fallback: NOT_APPLICABLE

For AI, Advanced, and Pool-member routing, external client requests succeeded, generated Xray routing targeted the expected N6 egress or balancer tags, access logs confirmed the final outbound tag, and the observed public exit matched the independent egress.

Pool fallback is NOT_APPLICABLE for this release because the v0.1.0 Pool UI has no fallback configuration entry. The acceptance process did not bypass the UI or modify DB state to manufacture a fallback result.
